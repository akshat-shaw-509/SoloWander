# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

The SoloWander team takes the security of our application and users seriously.

If you discover a security vulnerability within SoloWander, please do **NOT** open a public issue. Instead, report it responsibly:

1. Email your findings to **akshatshaw99@gmail.com**.
2. Include details of the vulnerability, step-by-step reproduction instructions, and proof-of-concept if possible.
3. Allow the maintainers reasonable time to investigate and address the vulnerability before public disclosure.

We will acknowledge receipt within 48 hours and work with you to remediate the issue promptly.
